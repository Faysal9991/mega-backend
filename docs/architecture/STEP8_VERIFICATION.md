## Changes, safety and remaining limits

Added identity-owned migration/queries/generated adapter; identity service and Google/Argon2 boundaries; nine HTTP operations; typed Google audience/authorized-party configuration; production composition; unit/HTTP/real PostgreSQL tests; OpenAPI fixtures/validation; schema/business/permission/ADR/setup/evidence documentation. Added expiry indexes and bounded cleanup before final migration reset/up and integration run; final cleanup cutoffs use statement_timestamp() so eligibility is fixed per statement and compatible with expiry index predicates. No query-plan/speedup claim is made. Source review fixed an ASCII normalization issue (Unicode Kelvin symbol could otherwise lowercase to ASCII). No tests were weakened.

Opaque bearer secrets and proofs persist only SHA-256 hashes; password credentials are Argon2id PHC strings. Integration fixtures use random planned Google subjects, account/installation IDs, aliases and independent bounded cleanup; cleanup also discovers committed IDs by the planned subjects after ambiguous failures. Only tracked fixture rows are deleted. Refresh history survives until absolute expiry; final tests exercise cleanup after that boundary. Runtime and migration credentials remain separated. No secret values were copied into documentation or argv.

Google JWKS behavior follows pinned go-oidc shared/coalesced refresh on missing signing key; raw provider errors are suppressed. Nonce/iat proves a fresh Google authorization interaction, not re-entry of the Google password; auth_time is not guaranteed by this mobile flow. Native azp IDs must be explicitly configured. Installation IDs can be reset, so the guarantees are for retained Google identity and explicitly restricted installation IDs, not permanent physical-device bans or detection of a person using a different Google account. Phone canonicalization validates syntax, not real number assignment/ownership. contact_email is provider-supplied metadata, never email login/linking/recovery authority. Forwarded client IP headers are not trusted; proxy address policy needs review before production. Fixed-window budgets may admit boundary bursts; hashing remains bounded. Cancellation does not interrupt native Argon2 midway; admitted work completes within the fixed cost and retains its slot.
